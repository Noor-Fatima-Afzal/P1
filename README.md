# Noor Fatima | Neuroscience / NeuroAI

An independently deployable static research portfolio focused on computational neuroscience, EEG analysis, neural decoding, and NeuroAI.

## Run
`npm run build` creates `dist/`. Serve `dist/` with any static host.

## GitHub Pages
The included GitHub Actions workflow builds `dist/` and deploys it to `https://noor-fatima-afzal.github.io/P1/` on pushes to `main`.
